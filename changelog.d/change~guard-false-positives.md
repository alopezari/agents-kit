- The shell guard no longer blocks deleting a linked git worktree or anything inside it (except the folder the session runs in), a Python or linter cache folder such as `__pycache__`, or a `$PWD/…` path it can place. Commands that only read PRODUCT.md, DESIGN.md or `.impeccable/` (`cat`, `ls … 2>&1`, `sed -n 1,80p`, `find` without actions, `git log`) no longer ask for approval. Deletes of the main checkout, home, `/` or unknown paths are still blocked.
- `bin/docs` no longer crashes on a `bin/__pycache__` folder, and the test suite no longer writes bytecode into the checkout.
