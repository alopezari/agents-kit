- `kit-ship` opens the pull request: with none open, it checks the evidence, pushes, writes the description, opens a PR ready for review and waits for its CI; with one open, it pushes and waits. `kit-create-pr` is retired, and a second `install.sh` removes its link. `kit-follow-pr` runs only when asked; a stored `follow-pr` switch is still accepted and gates nothing. After the merge, and only when asked, `kit-ship` follows the repo's `~/.agents/repos/<repo>/ship.md` (Deploy, Smoke checks, Rollback, Installed on this machine), drafting it the first time. The status line shows `ship` where it showed `create-pr`.
