- The core flow no longer has a staging phase: nothing holds `gh pr create` or `gh pr ready` for staging results, and `bin/staging`, the staging stamp, the `staging` phase switch and the `/flow` pane's Pass and Fail buttons are gone. A profile can add staging back for the repos that have a staging server.
- Validate now ends with a checks guide (`bin/reports path checks-guide`): optional steps before the merge (`M1`…) and the steps after it (`P1`…). The PR description lists each step with who runs it, or with its latest result. A branch's older staging guide is still read, its `S` steps as steps before the merge.
