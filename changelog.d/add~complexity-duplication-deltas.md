- kit-review's Maintainability reviewer gets measured structure facts about the change, from the new `bin/structure-facts <base>`: the cognitive complexity and NLOC of each function the change touches, adds or removes, at the base and the head, with each file's total, function count and largest function; and the copy-pasted blocks the change adds. Nothing gates on a number. It needs the optional `lizard` (`pipx install lizard`) and `jscpd` (`npm install -g jscpd`); without them, or when a tool fails or times out, the facts say what wasn't measured and the review goes on.
