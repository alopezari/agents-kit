- The shell guard reads code, not text: a grep pattern, an echoed or quoted sentence, a heredoc fed to cat, tee or an interpreter that starts no process, no longer trips its rules or the PR gates (the approvals check reads only Python's string literals; other languages naming the folder still ask), while `bash -c`, `eval`, a heredoc fed to a shell and a spawning script still count, and quoted SQL still counts when a SQL client or driver is in the command. `rm -r "$T"` resolves a `T=` path or `$(mktemp …)` the same command assigns, `$TMPDIR` and `${TMPDIR:-/tmp}`; `gh pr create --help` skips the PR gate; and a deny whose match is only in text says so.
