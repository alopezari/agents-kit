- In Claude Code with the kit plugin, each phase now runs on the model agreed for it. The first build goes to an agent for the spec's risk tier: Sonnet at medium effort for low risk, Sonnet at high for standard risk or no spec, Opus at high for high risk. The review lenses run on Opus at high effort, validation's checks run on a Sonnet runner while the session judges them, and the PR description is written on Sonnet. The other model family's readings are pinned to `gpt-6.1-sol` at high effort from Claude, and to Opus at high from Codex. In Codex, or with the plugin off, the session does all of this itself, as before.
