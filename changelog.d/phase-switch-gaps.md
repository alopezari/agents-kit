- Repo- and branch-scope phase switches and `review-rounds` set before this version are no longer read, so those phases count as on again: switch them again (`phase off <phase> repo`, `/flow off <phase> --repo`, and the same for branches). Global switches are kept.
- A phase switch applies to exactly the repository it was set in: two repos whose checkouts share a directory name (`a/app` and `b/app`) no longer share switches, while every worktree of one repo still does. A clone or a repo moved to another path starts with none.
- A branch renamed with `git branch -m` keeps its branch-scope switches and re-check rounds from its first read or write, unless a branch with the old name exists again by then. A reflog that can't be read is said, and every phase counts as on, as with an unreadable switch file.
- `review-rounds` set while a switch file at another scope can't be read now says the value was saved, names the file, and that the review runs 1 re-check round until it's fixed or deleted, instead of saying every phase counts as on.
- Two status-line refreshes of one branch at once no longer fail on a shared temporary file, and a branch recreated after `prune-merged` deleted it gets its own status label at once instead of after up to a minute.
