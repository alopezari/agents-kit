- Triage sizes a change by its code, not its prose. A whole-line comment raises no risk signal or lens, judged by the file's language (`//`, `/*` and docblock lines, `#`, `--`, `<!--`), while a prefix that is code there stays code (`#define`, `#[Attribute]`, a shebang, WordPress block markup, code after a comment's closer). `login`, `payment`, `migration`, `capabilit` and `cron` fire only in code shapes (a call, a longer name, a receiver, an assignment, a PHP array key, a declared type, a cron schedule), not as a word in a sentence or a JSON key. Untracked `.jsonl`, `.ndjson`, `.log`, `.out` and `.err` files no longer count toward the tier; they still reach the review stamp and bundle. Changes like #120 and #121, which came out high for a prose line and a `"capabilities"` key, now come out standard.
