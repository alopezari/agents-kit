- The decision page's summary has a Signals row after Gates: the quality signals `quality-log pr` last recorded for the branch's pull request (size, test files touched and deleted, verify and whether it was current, red check, diff coverage, weakened tests), shown as a snapshot with its time. Deleted test files, weakened tests, a failing or empty verify, a stale verify, a failed red check and a line recorded before the last commit are marked as needing you; a value the log doesn't hold shows as unknown, and a verify that never ran shows as none. When the log has no line for the pull request, the row says so: not recorded, not in the last 2 MB of the log, or unavailable with the reason the log or the PR couldn't be read.
