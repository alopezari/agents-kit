- A DROP DATABASE, DROP TABLE or TRUNCATE TABLE statement the shell guard refuses can now also be allowed by a message that only asks for it in plain words, in Spanish or English: "Sí, borra las bases de prueba", "drop the test databases", "vacía las tablas de prueba". Anything else in the message (another instruction, a question, a condition, a quote, code) and it grants nothing; the `allow DROP DATABASE` line, which can be followed by anything, works as before and also covers DROP SCHEMA.
