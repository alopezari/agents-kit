- Once you approve an MCP write (by naming the service in your message, in the dialog, or with the approval file), later writes in the same session to the objects it touched no longer ask again for 24 hours: the agent can update, comment on or attach a link to the Linear issue it just created for you in your next message. Creating another object, or writing to one you haven't approved, still needs you. A profile turns this on per service with an `objects` rule in `mcp-writes.json` (`direct_objects` for a direct server) naming the input fields that carry the object's id and the field a create returns; without one, nothing changes. A new PostToolUse hook on MCP calls records the objects, for Claude Code and Codex: run `~/.agents/install.sh` to wire it, and approve it in Codex.
