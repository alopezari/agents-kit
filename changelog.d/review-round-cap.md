- The self-review stops after one re-check by default: the same model re-reads the whole change after fixes, and the other model family gets one re-check of the fixes alone, not the whole change again. Findings from it are fixed only when confirmed, high severity and cheap; the rest go under Open for the PR reviewer. Fixes from follow-pr and validate get the same-model re-check, with no new cross-model round. Set the number of re-check rounds with `review-rounds <0-9> [branch|repo|global]` as the first line of a message, or `/flow review-rounds <0-9> [--repo|--global]` in Claude Code; 0 ends the review after the first pass and its fixes, and `~/.agents/bin/phase review-rounds` prints the value in effect.
