- Switch a phase of the flow off, or back on, for one branch, one repo or every repo, with the first line of a message: `phase off validate repo`, `phase on validate`. The phases are spec, self-review, validate, staging, verify, ci, follow-pr and audit; the PR gates and the stop hook skip what is off, the status line ends `· off: <phases>`, `bin/phase switches` lists them, and the PR validation section names each one skipped.
