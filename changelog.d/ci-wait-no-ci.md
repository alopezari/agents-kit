- After a push in a repo that runs no CI, the stop hook no longer asks the agent to wait, and `ci-wait` says so at once (exit 5) instead of waiting 5 minutes for checks that never come. "No CI" needs a commit with no CI config file and no checks on the default branch, the parent or the last 5 pull requests, so CI that reports through commit statuses or only on pull requests is still waited for.
