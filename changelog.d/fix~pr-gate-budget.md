- The `gh pr create` gate answers on a busy machine instead of blocking with "The guard failed (TimeoutExpired…)": it reads the review, the validation and the PR's target in one stamp process that asks git each question once, about 25 git calls and one Python start where it took about 85 and four. Its answers and their texts are unchanged. When that process can't answer (it is killed, exits with an error, or prints nothing, half an answer or one the guard doesn't expect), the pull request is blocked with a message that names the stamp check.
