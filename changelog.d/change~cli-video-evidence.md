- CLI, API and database checks the agent runs in kit-validate get a terminal video beside their log, from the same run: the new `bin/evidence-video <id> <command> [args...]` runs the check through `bin/evidence` in a terminal VHS records, leaves `<id>.txt` and `<id>.webm` in the evidence directory, and exits with the check's code. Past 120 seconds (`EVIDENCE_VIDEO_MAX`) it stops the check, saves nothing and exits 124; without vhs it runs `bin/evidence` alone and says there is no video. The video is never uploaded. The decision page shows a log and a video with the same name as Video and Log tabs, Log first unless the check passed. vhs (`brew install vhs`) is a recommended dependency.
