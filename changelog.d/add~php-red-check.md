- The automatic verify runs the red check for PHPUnit too: when a change edits both PHP tests and PHP code, the changed test classes run on a pristine copy of the merge-base, and verify fails when all their cases pass there. A red check it cannot run, or one whose run on the merge-base gives no case of the changed classes, is reported as `skipped:`.
- The automatic verify reports diff coverage of the related PHPUnit run when `php` can collect coverage (PCOV with `pcov.enabled` on, or Xdebug): how many changed PHP lines the related tests ran and which they didn't. It never fails the run; without a coverage driver, it says so.
