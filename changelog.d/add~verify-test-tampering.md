- The stop hook asks the agent to justify each test it weakens, once per session each: an assertion removed and not added back anywhere, a strict matcher (`assertSame`, `toEqual`, `assert a == b`…) swapped for a loose one (`assertNotNull`, `toBeDefined`, bare `assert x`…), or an expected literal changed while the branch also changes code. Covers PHPUnit, Jest/Vitest and pytest, on an assertion's first line. `stop_checks.py verify` prints the same findings as `warning:` lines without changing its verdict or stamp.
